# Snapcraft ConfDB Builder

A Linux desktop workbench for authoring and publishing Snapcraft ConfDB schema
assertions.

## Development

Run `flutter pub get`, then `flutter run -d linux`.

## Confinement

The future packaged application uses classic confinement because it needs to
orchestrate host `snap`, `snapcraft`, and the user's GPG keyring.
